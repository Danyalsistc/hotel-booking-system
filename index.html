How booking works

  1. 1

    Create an account

    Register once, then sign in. Your bookings are tied to your account.

  2. 2

    Choose your dates

    Pick a room type, your check-in and check-out dates and the number of guests.

  3. 3

    Check availability

    The system checks real rooms against existing bookings for those exact dates.

  4. 4

    Request your booking

    Your request is saved with the status pending until staff confirm it.

No payment is taken anywhere in this system, and no card details are collected or stored.

About this project

Hotel Booking System is a student project built for ICT304 Capstone 2. It models a single hotel offering six room types and demonstrates the full booking cycle: registering an account, signing in, checking availability for a date range, requesting a room, and having staff confirm or cancel that request.

Availability is worked out against individual physical rooms rather than room categories, so two guests can hold the same room type on the same night as long as separate rooms are free. Prices, guest limits and room details all come from a MySQL database, and every booking is written to that database inside a transaction so the same room cannot be allocated twice.

The site is built with plain HTML, CSS, JavaScript, PHP and MySQL. It uses no frameworks, no external services and no third-party fonts, so it runs entirely offline from a local XAMPP installation.

Demonstration project. This is coursework, not a real hotel. The rooms, prices and availability shown here are sample data, and no genuine reservation can be made through this site.
